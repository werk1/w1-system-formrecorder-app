# Documentation Lifecycle Contract

## Lifecycle

Documents follow: IDEA -> PLAN -> ROADMAP -> REPORT

## Placement

| Type | Location |
|---|---|
| Bugs | `docs/bugs/` |
| Non-defect work | `docs/tickets/` |
| Plans | `docs/planning/` |
| Roadmaps | `docs/roadmaps/` |
| Reports | `docs/reports/` |
| Review reports | `docs/reports/review/` |
| Review templates | `docs/templates/` |

## Current Truth vs History

Active contracts, system files and active docs are current truth. Superseded documents belong in reports or archive. Do not keep obsolete versions in active locations.

## Done Folder Rules

Completed work items move to the `done/` subfolder of their parent. They are not deleted.

## Forbidden

Do not create a top-level `docs/reviews/` folder. Review reports belong under `docs/reports/review/`.
