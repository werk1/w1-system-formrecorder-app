# SYSTEM_TESTING

Generated by `w1-system-app-creator` for `w1-system-pdfedit-app`.

This file is a mandatory local source for this app. All rules required to work in this repository are contained in local files.

This document defines the verification policy for `w1-system-pdfedit-app`.

## App-Host Verification

Run inside the target app host:

```bash
npm run generate:types
npm run generate:importmap
npm run lint
npm run test:int
npm run test:e2e
npm run build
```

If the host has different scripts, record the exact commands used in the
ticket, review or report.

```bash
npm run generate:importmap
npm run generate:types
npx tsc --noEmit --incremental false
npm run build
```

Run all four commands when changing Payload collections, globals, schemas, package imports or generated types.

## Docker Development

```bash
npm run dev:docker
npm run dev:docker:logs
npm run dev:docker:down
```

Run Docker checks when Dockerfile, docker-compose files, env variables or Payload initialization changes.

## Module-Specific Checks

Run module-specific checks when the module's routes, Payload collections, env variables or package integration changes.

## Documentation-Only Changes

For documentation-only changes:

1. Verify paths and links by inspection or available link tooling.
2. Check that local and local file links are both correct when a repo can
   be opened standalone.
3. Do not run app builds unless the docs also change build/test behavior.

2. Run `git diff --check` to confirm no whitespace errors.
3. Do not run app builds unless the docs also change build/test behavior.

## Package Defects

App-host verification does not replace package-level checks. When a defect is package-owned, document the app-facing symptom locally and fix the defect in the owning package repository using that package's own `npm run type-check`, `npm run build` and `npm run test`.

## Testing Layers

| Layer | Primary use | Scope |
| --- | --- | --- |
| Package-local checks | Fast iteration inside one reusable package | One `w1-system-*` repo |
| App-host checks | Next.js/Payload integration and generated types | `w1-system-core-v2`, generated apps, `w1-system-ticketing-app` (ticketing system app) |
| App scripts | Broad maintenance, package build or health checks | App root |
| Docker app checks | Runtime integration, Payload, database and deployment-like behavior | App hosts |

|---|---|---|
| Type check + build | Fast app-host verification | This app |
| Docker app checks | Runtime, Payload, database, deployment-like | This app |
| Package-local checks | Package defect verification | Owning package repo |
